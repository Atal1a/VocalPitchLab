# VocalPitchLab 1.1.1

[简体中文](RELEASE_NOTES_1.1.1.md)

## Installation and upgrades

- Reduced the full offline installer size by about 27%.
- Added a standalone update for 1.1.0 that reuses the installed runtime and models.
- Added pre-update checks and recovery after an interrupted update.

The recognition models and analysis results are unchanged.

For a first-time installation or repair, download `setup.exe` and all `.bin` volumes, put them in the same folder, and run the installer.

To upgrade from 1.1.0, download `VocalPitchLab-1.1.1-windows-x64-update-from-1.1.0.exe`. Close the app before running it. For other versions or incomplete installations, use the full installer to upgrade in place.
