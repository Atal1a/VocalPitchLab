# VocalPitchLab 1.3.0

[English](RELEASE_NOTES_1.3.0.en.md)

## 新增功能

- 分离完成即可导出音轨，音高和音符分析会在后台继续。导入时也可选「仅导出音轨」，之后在任务中补做完整分析。

## 问题修复

- 切换和声时沿用曲库中保存的原录音。重新导入同一录音可修复损坏的分析结果，保留原条目和视图。
- 修复循环终点设在曲尾时播放停止的问题。
- 修复重新导入后撤销移除产生重复曲目，以及批量移除后 Shift 多选计数错误。

## 性能优化

- 批量入队和再次打开曲目更快，保存播放进度时的写盘开销更小。
- 分离完成后清理临时音频，减少磁盘占用。

## 安装与升级

新增 CPU 离线安装包，继续提供支持 GPU 加速的 NVIDIA 版。已安装 1.2.0 Windows x64 版可用单文件更新包升级到 NVIDIA 版。见[安装说明](INSTALLATION_1.3.0.md)。

- CPU 版缺少安装标记时，可用同版本完整包修复。
- 更新失败并回滚后，Windows 的应用列表会恢复显示原版本。
