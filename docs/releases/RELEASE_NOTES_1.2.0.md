# VocalPitchLab 1.2.0

[English](RELEASE_NOTES_1.2.0.en.md)

## 性能优化

- **降低播放时的绘图开销**。音高图复用已绘制的曲线和音符块，播放线独立刷新，减少连续播放时的重复绘制。还可在「设置 → 外观」开启「降低运行负载」，关闭侧栏模糊和面板阴影。
- **按需开启音频分离**。在「设置 → 音频分离」可独立开关人声分离和和声分离，两项默认开启。只想从伴奏中提取人声时，可以关闭和声分离，跳过这一步处理。两项都关闭时，新导入的歌曲会直接用原曲分析音高，可缩短等待时间，但伴奏可能被误识别为人声音高。

## 功能改进与新增

- **导出分离音轨**。分析完成后，在播放区选择「导出音轨」，即可将可用的音轨另存为 WAV。两项分离都开启时，可分别导出主唱、伴奏和和声。仅开启人声分离时，可导出人声和伴奏。仅开启和声分离时，可导出主唱，以及和声与伴奏的混合轨。
- **改进钢琴试听**。使用预载采样，点击图表左侧的音名后出声更快。按住可延音，松手释放。试听音量上限也有所提高，便于和原曲一起听辨音高。
- **新增英文界面**。在「设置 → 界面语言」选择 English 即可切换，歌曲库、播放控件、图表和分析提示会即时更新。软件会记住语言选择。

同时修复了批量导入和界面提示中的一些问题。

## 安装与升级

使用 Windows x64 完整安装包。分卷版需将安装程序与全部 `.bin` 文件放在同一文件夹。单文件版可直接运行安装程序。

正式版 1.1.2 用户可使用独立更新包，复用现有运行库和模型。也可关闭软件后，使用完整安装包覆盖到原目录。两种方式均保留歌曲库、设置和分析结果。详见[安装说明](../INSTALLATION.md)。
