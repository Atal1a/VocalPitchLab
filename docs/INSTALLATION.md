# 安装与常见问题

[English](INSTALLATION.en.md)

适用于 VocalPitchLab 1.3.0 Windows x64。安装包、分卷和更新包的文件名见 [1.3.0 安装说明](releases/INSTALLATION_1.3.0.md)。

## 安装

1. CPU 版只有一个安装程序。NVIDIA 版需要安装程序和全部配套分卷。
2. 将 NVIDIA 安装程序和分卷放在同一文件夹，保持原文件名。运行所选版本的 `.exe`，按向导完成安装。
3. 如果系统缺少必要的微软运行组件，安装程序会离线补装。此时 Windows 可能请求管理员权限；已有足够新版本时会跳过。
4. 运行组件需要重启时，向导会在安装完成后提示，可选择立即重启或稍后重启。重启后再启动 VocalPitchLab，无须重新运行安装程序。

安装完成后，从开始菜单或桌面快捷方式启动，也可打开安装目录中的 `VocalPitchLab.exe`。

兼容的 NVIDIA 显卡和驱动可以加速分析；本版 GPU 运行库要求 Windows NVIDIA 驱动 570.65 或更新版本，且驱动须支持具体显卡型号。没有可用的 GPU 加速时会使用 CPU，分析明显较慢。

## 更新

已安装正式版 1.2.0 时，可关闭 VocalPitchLab 后运行单文件更新包，升级到 1.3.0 NVIDIA 版。更新包会复用现有运行库和模型。若安装记录未被识别，可手动选择原安装目录。

更新包不适用时，用对应的完整安装包覆盖到原目录。切换 CPU 与 NVIDIA 版时，先卸载现有版本。使用同一个 Windows 用户账户且旧安装记录有效时，向导会自动沿用原安装目录。

完整包会替换程序和运行库，并保留歌曲库、设置与分析结果，也适用于首次安装和修复缺失或被修改的安装文件。

建议提前备份 `%LOCALAPPDATA%/VocalPitchLab` 中的歌曲库与分析数据。安装中断后，重新运行完整安装包完成安装或修复。

源码包供开发使用，普通安装无需下载。

## 常见问题

**缺少分卷或文件损坏**：检查是否下载了同一版本的全部文件，文件名是否被添加了 `(1)` 等后缀。

**运行组件安装未完成**：允许必要的管理员权限；如果是公司管理的电脑，请联系管理员。组件安装日志位于 `%LOCALAPPDATA%/VocalPitchLab/installer-logs`。不要从不明网站下载单独 DLL。

**原唱或人声无声**：在设置中开启“兼容播放”，完全退出软件后重新启动，再播放已有分析结果，无须重新分析。

**分析慢或转用 CPU**。在「设置 → 音频分离」关闭人声和和声分离后，新导入的歌曲会直接用原曲分析，伴奏可能被识别为人声音高。使用 NVIDIA 显卡时，可检查驱动版本是否支持显卡。

**分离后缺少歌声**：在当前歌曲的播放区将“和声分离”切换为“关”。已有结果会直接复用，首次切换可能需要分析。部分合唱、高音叠唱可能被和声分离模型削弱。

**数据保存在哪里**：歌曲库和分析数据在 `%LOCALAPPDATA%/VocalPitchLab`。卸载保留这些数据，也不会卸载其他软件可能共用的微软运行库。
