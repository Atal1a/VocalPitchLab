# Windows local preview build

For the newer clean Python environment rebuild and evidence, see ../CLEAN_BUILD.md and rebuild_environment.py. It installs hash-locked wheels rather than copying the development site-packages. It does not compile an installer. The older preview builder below remains explicitly a local QA snapshot tool.

This preview is for local installation QA, not public redistribution. The builder refuses to run without `--local-preview`. It packages the current validated runtime rather than claiming a reproducible clean dependency build.

1. From the development environment run `python installer/build_preview.py --local-preview`.
2. Obtain Inno Setup from https://jrsoftware.org/isdl.php and verify its signature.
3. Run `ISCC /DStageDir=<absolute build/local-preview path> installer/VocalPitchLab.iss`.
4. Test the resulting setup in a disposable Windows Sandbox. `sandbox_check.py` validates GUI, worker launch and CPU analysis using the installed Python.

The installer includes an uninstaller, per-user install and shortcuts. Data under `%LOCALAPPDATA%/VocalPitchLab` is intentionally preserved on uninstall. The current preview bundles model files for local QA only; do not upload it. It is unsigned.

Public release gates: explicit BS/model redistribution review; corresponding third-party notices/source obligations; clean dependency installation with pinned artifacts; startup/model-download UI; installation/upgrade/uninstall tests; representative full-song CPU and low-VRAM measurements; removal of unused packages to reduce size. `model_setup.py` implements pinned checksums and safe archive extraction, but public provisioning is deliberately blocked while license review is unresolved.

## Offline trimmed preview (2026-09-25)

The chosen distribution remains fully offline: production models and CUDA-enabled PyTorch are bundled. On-demand installation is deferred. Compatible NVIDIA GPUs use CUDA; other machines retain CPU fallback. PyTorch alone does not enable acceleration on every GPU.

Build with `python installer/build_preview.py --local-preview --trim`, then `ISCC /DStageDir=<absolute build/slim-preview path> /DSlimBuild installer/VocalPitchLab.iss`. The trim builder requires a fresh stage and only modifies its disposable build subdirectory. `build/trim-report.json` records every removed file.

The conservative trim removes C++ static libraries/headers, Qt development tools and the unused FCPE experiment. All production weights and inference DLLs remain. Do not blanket-delete dependency test directories: NumPy imports a helper from its tests during normal SciPy execution. Those directories were restored following the first validation failure. Final removed size: 909,539,011 bytes. Models and Torch DLL checksums match the original stage (45 files checked). The trimmed runtime passed GUI queue analysis and original/vocal playback; see `outputs/slim-validation`.

Packaging compression savings must be measured separately from installed directory savings. This remains an unsigned local QA preview pending redistribution review and independent clean-Windows validation.

Measured setup size: 3,945,336,309 bytes, versus 4,057,089,041 bytes previously (111,752,732 bytes smaller). The setup and SHA256 sidecar are in `dist/VocalPitchLab-0.1.0-offline-slim-preview-setup.exe`. The stage after validation includes regenerated bytecode and totals 6,399,054,775 bytes; the file-removal report excludes regenerated bytecode.

Actual isolated installation returned 0. Using only its bundled runtime, the QML queue completed the 20-second RISE clip on CUDA in 31.69 seconds; both original and vocal playback advanced. Uninstall returned 0 and preserved the independent library and result. Evidence: `outputs/slim-installed-validation`. This is a same-host test, not independent clean-PC certification or a speed comparison against the previous package.

## GitHub offline split installer

### Offline VC++ prerequisite (source update, not rebuilt)

`VocalPitchLab.iss` includes `vc_redist.iss`. Before compiling, preserve the original Microsoft x64 redistributable at `work/installer-tools/prerequisites/vc_redist.x64.exe`, or supply `/DVCRedistPath=<absolute file>`. Missing files stop compilation. `powershell -NoProfile -File installer/prepare_prerequisites.ps1 [-SourceFile <cached official installer>]` obtains/copies and verifies the pinned artifact. The mutable Microsoft download URL must still match the pinned SHA256; a changed upstream release requires an explicit manifest and Inno version/hash update. Do not replace it with a third-party runtime pack.

The setup carries the prerequisite internally (18,731,856 bytes before installer compression). It checks the x64 runtime registration in both registry views; versions at least 14.51.36247 are retained. Missing/older versions trigger the original Microsoft installer with elevation, quiet mode, and no automatic restart. The application itself remains per-user. Refused elevation or installation errors stop preparation with an explanation. Restart-required codes stop preparation and request a Windows restart followed by rerunning setup. Exit 1638 is accepted only if a sufficient runtime is registered. Runtime SHA256 is checked before execution. Logs persist under `%LOCALAPPDATA%/VocalPitchLab/installer-logs`. Uninstall never removes the shared Microsoft runtime.

Per the user's explicit instruction, no tests or installer compilation were run after this change. Existing files in `dist` do **not** include it. Previous Sandbox results establish that manually installing the official runtime fixes the dependency failure; they do not validate this new setup integration. Third-party distribution eligibility remains separately tracked.

Compile with `ISCC /DStageDir=<absolute build/slim-preview path> /DSlimBuild /DGithubAssets installer/VocalPitchLab.iss`. Output is isolated in `dist/github-offline-preview` so the single-file setup is preserved. Inno Setup uses 1,500,000,000-byte slices, below GitHub's per-asset limit.

After compilation, run `python installer/prepare_github_assets.py` to check every binary asset is below 2 GiB and generate SHA256SUMS.txt, assets.json and Chinese installation instructions. Upload the setup and **all** matching `.bin` files as Release attachments only after public redistribution gates are met. Do not commit binaries to Git. Users download all volumes into one folder and run the setup executable; no external decompressor or install-time model download is needed.
