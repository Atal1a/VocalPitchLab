# VocalPitchLab

面向流行音乐的人声音高分析软件，在 Windows 本地运行。导入歌曲后，提取人声，用音高曲线和主要音符块展示歌手的演唱旋律，方便试听、观察和比对。

- **人声分离**：分离人声与伴奏，可选择是否进一步分离和声。
- **音高展示**：结合连续音高曲线与主要音符块，查看旋律走向、滑音和颤音。
- **试听比对**：切换原曲与分离人声，点击左侧音名试听标准钢琴音。
- **播放控制**：支持循环播放、音量调整，以及时间和音域缩放。
- **歌曲管理**：保存分析结果和查看位置，支持批量管理、深色与浅色主题。
