# VocalPitchLab mark

The V follows the user's local ComfyCanvas and PartyLink brand family: dark navy italic serif lettering over a pale-blue to violet surface. Reference files inspected locally:

- E:/PartyLink/local-edition/app/build/partylink-icon.png
- E:/comfyui_v5.5/comfyui_v5.5/mobile_server/static/icons/icon-512.png

V is outlined from Fraunces Italic (weight 800, optical size 144, soft 100, wonk 1 where available). Font license retained in OFL-Fraunces.txt. SVG is resolution-independent; PNG and multi-size ICO are rendered derivatives. No font installation or network dependency is required at runtime.

Used in the sidebar and Windows application icon. It does not replace another project's files.
